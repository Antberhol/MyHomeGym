# 12. Glosario

[← Índice de la ERS](../REQUISITOS_FUNCIONALES_Y_ACEPTACION.md)

| Término | Definición |
| --- | --- |
| **1RM** | *One-repetition maximum*: el peso máximo que se podría levantar una sola vez. MyHomeGym lo **estima** con la fórmula de Epley a partir de series de varias repeticiones. |
| **Calentamiento** | Serie ligera previa a las series de trabajo. No cuenta para volumen, récords, mapa muscular ni doble progresión. |
| **Carpeta** | Agrupación de rutinas para organizarlas (por ejemplo, "Fuerza" o "Verano"). |
| **Catálogo** | Los 876 ejercicios de free-exercise-db incluidos en la app, comunes a todos los usuarios. |
| **Descanso** | Tiempo entre dos series de un mismo ejercicio. Se configura por ejercicio de rutina. |
| **Doble progresión** | Método de progresión: se mantiene el peso hasta llegar al máximo del rango de repeticiones en todas las series, y entonces se sube el peso. |
| **Drop set** | Serie en la que, al llegar al fallo, se baja el peso y se continúa sin descanso. |
| **Entreno guiado** | Entreno que sigue una rutina: ejercicios, series y descansos ya definidos. |
| **Entreno libre** | Entreno sin rutina: los ejercicios se añaden sobre la marcha. |
| **Entreno en curso** | El entreno que se está haciendo, aún sin terminar. Se guarda en el navegador hasta que se termina o se descarta. |
| **Epley** | Fórmula de estimación del 1RM: kilos × (1 + repeticiones / 30). |
| **ERS** | Especificación de Requisitos Software: este documento. |
| **Fallo (al fallo)** | Serie en la que se hacen repeticiones hasta no poder hacer una más con buena técnica. |
| **IMC** | Índice de masa corporal: peso (kg) / altura (m)². Es un indicador orientativo, no un diagnóstico. |
| **JWT** | *JSON Web Token*: credencial firmada que demuestra la identidad del usuario ante el servidor durante 15 minutos. |
| **Mapa muscular** | Figura anatómica coloreada según el volumen que ha recibido cada músculo en un periodo. |
| **Músculo principal / secundario** | El músculo que más trabaja un ejercicio, y los que ayudan. En el mapa, el principal cuenta el 100 % del volumen y los secundarios el 35 %. |
| **Nivel (del mapa)** | De 0 a 4: cuánto se ha trabajado un músculo en relación con el más trabajado del periodo. |
| **Plantilla** | Rutina prediseñada (Full Body 3 días, Push Pull Legs, Upper Lower 4 días, Fuerza 5x5) que se copia a las rutinas del usuario. |
| **PWA** | *Progressive Web App*: web que se puede instalar en el móvil o el escritorio como si fuera una app. |
| **Racha** | Días (o semanas) seguidos con al menos un entreno, contando desde hoy o desde el periodo anterior. |
| **Récord personal (PR)** | La mejor marca del usuario en un ejercicio: peso máximo, más repeticiones con un peso, mejor serie o mejor sesión. |
| **Repeticiones objetivo** | Repeticiones que se pretende hacer en cada serie: un número (`5`) o un rango (`8-12`). |
| **Rutina** | Plan de entrenamiento con nombre, días de la semana y una lista ordenada de ejercicios. |
| **RPE** | *Rate of Perceived Exertion*: esfuerzo percibido de una serie, de 6 (fácil) a 10 (no podía hacer ni una más). |
| **Serie** | Bloque de repeticiones seguidas de un ejercicio con un peso. |
| **Serie de trabajo** | Cualquier serie que no es de calentamiento. |
| **Token de refresco** | Credencial de larga duración (30 días) que permite obtener un JWT nuevo sin volver a escribir la contraseña. Es de un solo uso. |
| **Volumen** | Kilos × repeticiones. El volumen de una sesión, de un ejercicio o de un músculo es la suma de sus series de trabajo. |
